## Note values

Each note value is half the previous one:

| Name (US) | Name (UK) | Beats in 4/4 |
|---|---|---|
| whole | semibreve | 4 |
| half | minim | 2 |
| quarter | crotchet | 1 |
| eighth | quaver | ½ |
| sixteenth | semiquaver | ¼ |

Every note value has a matching **rest** (a silence of the same length).

## Dots and ties

A **dot** adds half the note's value: a dotted half = 3 beats; a dotted quarter = 1½ beats. The dotted-quarter + eighth rhythm is everywhere in heroic themes (think of a horn call).

A **tie** connects two notes of the *same pitch* into one longer sound — used when a note crosses a barline or needs a length no single value can express.
